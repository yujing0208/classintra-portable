【这是什么】
  一个绿色便携包：自带 Node.js 运行时和全部依赖，
  放进 U 盘 / 移动硬盘后，在任何 Windows 10/11（64 位）电脑上
  双击脚本即可运行，不需要目标电脑安装任何开发环境。

【目录结构】
  ClassIntraPortable/
  ├─ 1-安装初始化.bat           首次使用：装依赖+生成配置+构建前端
  ├─ 2-启动ClassIntra.bat       前台启动服务器并打开浏览器
  ├─ 3-停止ClassIntra.bat       停止前台服务器
  ├─ 4-更新代码.bat             在线更新源码（需要电脑装有 git）
  ├─ 5-captive热点劫持-启动.bat 热点劫持（管理员，前台调试）
  ├─ 5.2-captive守护安装.bat    热点劫持无窗口守护（装/卸，推荐）
  ├─ 5.5-captive诊断.bat        服务失败时一键查原因（管理员）
  ├─ 6-停止Captive.bat          停止热点劫持（兼容前台/守护）
  ├─ 7-安装守护与开机自启.bat   ClassIntra PM2 守护 + 开机自动恢复
  ├─ 8-查看状态与日志.bat       PM2 状态与日志
  ├─ 8-卸载守护.bat             卸载守护与开机自启
  ├─ 9-安全退出.bat             弹出 U 盘前必做
  ├─ runtime\                  便携 Node.js + pnpm + PM2 数据（勿删）
  ├─ apps\ClassIntra\          ClassIntra 源码与数据
  ├─ apps\captive\             captive 热点劫持工具
  └─ README.txt                本说明

【首次使用（新电脑 / 第一次拷贝到 U 盘后）】
  1. 把整个 ClassIntraPortable 文件夹拷贝到 U 盘
     （电脑没网也能用，但首次需要网络装依赖）
  2. 双击 1-安装初始化.bat，等待完成（约 3-10 分钟，走国内镜像）
  3. 用记事本打开 apps\ClassIntra\server\.env，按需修改：
       ADMIN_USER_IDS=250100    ← 改成你的班管ID（250100=25届01班）
       如需测试账号，去掉 DEV_PASSWORD 前的 # 并设个密码
  4. 双击 2-启动ClassIntra.bat

【日常使用】
  双击 2-启动ClassIntra.bat
  → 自动打开浏览器访问 http://localhost:9001
  → 关闭弹出的黑色窗口 或 双击 3-停止ClassIntra.bat 即可停止

【稳定运行：开机自启 + 崩溃自动重启（推荐教室电脑用）】
  1. ClassIntra 守护：双击 7-安装守护与开机自启.bat（管理员）
     → 用 PM2 托管服务：进程崩溃会自动重启（退避策略）
     → 注册"登录 Windows 自动恢复服务"的计划任务
  2. captive 无窗口守护：双击 5.2-captive守护安装.bat（管理员，选 1）
     → 注册开机自启计划任务，watchdog 每 15 秒健康检查、崩溃自动拉起
     → 全程无黑窗口、不占任务栏，日志写入 apps\captive\logs\
  之后日常无需任何手动启动，也无窗口打扰：
    - 教师机任务栏全程干净，只有浏览器访问页面
    - ClassIntra 崩溃 → PM2 自动重启；captive 崩溃 → watchdog 自动拉起
  辅助：
    8-查看状态与日志.bat   看 ClassIntra(PM2) 状态与日志
    5.5-captive诊断.bat    看 captive 是否在跑、为何失败（只读）
    8-卸载守护.bat         卸载 ClassIntra 守护与开机自启
    5.2（选 2）            卸载 captive 守护与开机自启
  ⚠ 前台调试模式（2-启动 / 5-启动）与守护模式二选一，别同时用。

【U 盘用完 / 弹出前】
  必做：双击 9-安全退出.bat
  → 停止所有服务并退出后台进程，避免文件被占用导致弹不出 U 盘

【教室上课场景（完整版）】
  0. 部署：运行 1-安装初始化 → 7-安装守护(ClassIntra) → 5.2-captive守护安装
  1. 电脑开"移动热点"，学生平板连上（密码你定）
  2. ClassIntra 页面：学生浏览器访问 http://<教师电脑IP>:9001
  3. captive 域名劫持：学生访问
       学科网 / 畅言智慧课堂(ai.changyan.com 等) / 问卷星(www.wjx.cn) / 智学网(zhixue.com)
     会自动跳转到本机 ClassIntra（无需学生任何配置）
  4. 全部后台无窗口运行；教师机可同时做别的（备课/放课件）
  5. 下课：双击 9-安全退出.bat 再关热点（弹出 U 盘前同样必做）

【常用信息】
  端口： 9001（网页/API） 10001（聊天 WebSocket） 10011（班级中继）
  数据： apps\ClassIntra\server\database\ 与 apps\ClassIntra\Resources\
        （备份=拷贝整个文件夹即可）
  卸载： 删除整个文件夹即可，不残留任何系统文件

【常见问题】
  * 双击 2-启动 报"前端还没有构建" → 先运行 1-安装初始化.bat
  * 端口被占用 → 检查 9001/10001/10011 是否被其他程序使用
  * 换电脑打不开 → 确认拷贝完整（尤其 runtime\node 与 node_modules）
  * .bat 乱码或闪退 → 已按中文系统 GBK 编码，正常双击即可。不要用记事本
    编辑/另存 .bat（会变回 UTF-8 导致乱码）；如需修改请用 VS Code 等编辑器
  * 需要 AI 对话 → 在 .env 里填 DEEPSEEK_API_KEY 或 OpenAI 等密钥
